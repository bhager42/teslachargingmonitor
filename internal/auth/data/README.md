# Common password list

`common-passwords.txt` is derived from
[SecLists](https://github.com/danielmiessler/SecLists)
`Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt`
(MIT License, Copyright (c) 2018 Daniel Miessler): entries NFKC-normalized,
lower-cased, de-duplicated, and only those of 8 or more characters kept
(shorter ones are rejected by the length rule anyway).
